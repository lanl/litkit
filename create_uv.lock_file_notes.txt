A uv.lock file is used during construction of the charliecloud container.
The uv.lock file is built from the repo's pyproject.toml file.

On the HPC frontend (not on a GPU node), do the following:

# Navigate to the litkit repo
cd /path/to/litkit

# Make sure that uv is available
python -V 
python3.12 -V
~/.local/bin/uv --version

# If uv is not available, install using Python
python3.12 -m pip install --user uv

# Create (or refresh) the lockfile, targeting Python 3.12
~/.local/bin/uv lock --python 3.12
