# LitKit Linting Notes

This project uses ruff (linting), black (formatting), and mypy (type checking).
All tools are configured in pyproject.toml.

================================================================================
INSTALLATION
================================================================================

Option 1: Install dev dependencies with pip
-------------------------------------------
pip install -e ".[dev]"

Option 2: Install dev dependencies with uv (if using uv)
---------------------------------------------------------
uv pip install -e ".[dev]"

Option 3: Install tools individually
------------------------------------
pip install ruff black mypy

================================================================================
RUNNING LINTERS
================================================================================

1. ruff (fast Python linter - replaces flake8/isort/pyflakes)
-------------------------------------------------------------

Check for errors (no changes):
    ruff check src/

Check and auto-fix:
    ruff check --fix src/

Check a specific file:
    ruff check src/litkit/cli.py

Show what rules would be violated (verbose):
    ruff check --show-fixes src/

2. black (code formatter)
-------------------------

Check formatting (no changes):
    black --check src/

Format all files:
    black src/

Format a specific file:
    black src/litkit/cli.py

Show diff without applying:
    black --diff src/

3. mypy (type checker)
----------------------

Type check the entire package:
    mypy src/litkit/

Type check a specific file:
    mypy src/litkit/cli.py

Ignore import errors (useful when deps aren't installed):
    mypy --ignore-missing-imports src/litkit/

================================================================================
QUICK WORKFLOW
================================================================================

# Full lint + format pass:
ruff check --fix src/ && black src/

# Check everything without modifying:
ruff check src/ && black --check src/ && mypy src/litkit/

================================================================================
CURRENT CONFIGURATION (from pyproject.toml)
================================================================================

[tool.black]
line-length = 100
target-version = ["py312"]

[tool.ruff]
line-length = 100
target-version = "py312"
fix = true
src = ["src", "tests"]
exclude = [".venv", "build", "dist", ".eggs", "*.egg-info", "workspace"]

[tool.ruff.lint]
select = ["E", "W", "F", "I", "UP", "B"]
ignore = ["E501", "D105", "D107"]

# cli.py has extra ignores:
[tool.ruff.lint.per-file-ignores]
"src/litkit/cli.py" = ["E402", "B006", "B008", "B023"]

================================================================================
RULE CODES EXPLAINED
================================================================================

E = pycodestyle errors (PEP8 style)
W = pycodestyle warnings
F = Pyflakes (unused imports, undefined names, etc.)
I = isort (import sorting)
UP = pyupgrade (modernize syntax for target Python version)
B = flake8-bugbear (common bugs and design problems)

Ignored:
  E501 = line too long (we rely on black for wrapping)
  E402 = module level import not at top of file (cli.py needs this)
  B006 = mutable default argument (cli.py uses this intentionally)
  B008 = function call in default argument (cli.py uses this intentionally)
  B023 = function uses loop variable (cli.py handles this safely)

================================================================================
VS CODE INTEGRATION
================================================================================

Install these extensions:
  - ms-python.python (Python)
  - charliermarsh.ruff (Ruff)
  - ms-python.black-formatter (Black)
  - ms-python.mypy-type-checker (Mypy)

Add to your settings.json:
{
  "python.defaultInterpreterPath": "/path/to/your/venv/bin/python",
  "[python]": {
    "editor.defaultFormatter": "ms-python.black-formatter",
    "editor.formatOnSave": true
  },
  "ruff.lint.run": "onSave",
  "mypy-type-checker.args": ["--ignore-missing-imports"]
}

================================================================================
SUPPRESSING WARNINGS
================================================================================

Inline suppression (ruff):
    x = 1  # noqa: E501

Inline suppression (multiple rules):
    x = 1  # noqa: E501, F401

Type ignore (mypy):
    x = some_untyped_call()  # type: ignore

================================================================================
COMMON ISSUES AND FIXES
================================================================================

1. "Unable to import 'faiss'" / "Unable to import 'numpy'"
   -> These are runtime dependencies, not installed in your dev environment
   -> Safe to ignore with: mypy --ignore-missing-imports

2. "line too long (82 > 79 characters)"
   -> This is flake8's default; ruff/black use 100 chars
   -> If seeing this, you're running flake8 not ruff

3. Import order changed by ruff
   -> Normal; ruff auto-sorts imports per isort rules
   -> Just run: ruff check --fix src/

4. "module level import not at top of file"
   -> cli.py has intentional late imports (lazy loading)
   -> Already suppressed in pyproject.toml for cli.py
